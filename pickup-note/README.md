# 픽업노트 (임시)

배달 라이더가 가게에서 받은 대우를 기록·공유하는 커뮤니티 웹앱 프로토타입.
새 레포로 옮기기 전까지 이 폴더에서 임시로 진행한다.

## 기능
- **가게 제보**: 가게명·동네·업종, 도착 후 대기 시간, 라이더 대우 점수(1~5), 불편/좋았던 점 태그, 메모
- **가게 평판**: 가게별 평균 점수·평균 대기 시간·자주 나온 태그, 검색·필터(주의/좋음/업종)
- **커뮤니티**: 말머리(자유/피해 공유/질문/꿀팁) 게시판, 공감, 댓글
- **대처법**: 증거 남기기, 조리 지연·폭언 대응, 도움받을 곳

## 현재 한계
- 서버가 없어 데이터는 브라우저 `localStorage`에만 저장된다(기기 간 공유 안 됨).
- 로그인 없이 닉네임만 사용한다.

## 실행
`index.html` 하나로 동작한다. `python3 -m http.server` 등으로 폴더를 띄워서 열면 된다.
