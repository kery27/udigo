매장 보관 공간 관리 시스템 🚀

매장 사진 위에 구역을 지정하고 물건 위치를 스마트하게 관리해보세요!

📍 1. 공간 지정 및 크기 변경

  • 구역 만들기: 사진 위를 드래그하면 구역이 생성됩니다.
  • 구역 이동: 생성된 구역의 가운데를 잡고 드래그하면 자유롭게 이동합니다.
  • 크기 조절: 구역 선택 시 나타나는 모서리의 흰색 점을 당겨서 크기를 조절하세요.

📦 2. 품목 등록 및 메모(코멘트)

  • 구역을 새로 그리거나 구역을 터치/클릭하면 상세 품목 지정 창이 열립니다.
  • 품목을 체크하면 상세 위치를 적을 수 있는 코멘트 창이 열립니다.

🔍 3. 위치 찾기 (스마트 검색)

  • 검색된 구역 버튼을 클릭하면 해당 위치로 이동하며, 정중앙에 빨간 화살표(▼)가 꽂힙니다.

🔄 4. 품목 이동 및 안전 삭제

  • 구역 간 이동: 구역에 표시된 품목 글자를 잡고 다른 구역으로 드래그하면 바로 이동합니다.
  • 안전한 삭제: 품목을 잡고 구역이 없는 빈 허공으로 멀리 떨어뜨리면 최종 삭제 여부를 묻는 팝업창이 작동합니다.
💡 팁: 검색된 구역 이름을 누르면 해당 위치로 이동합니다. (클릭해서 닫기)
